# 小红书图文：出图视觉规范

定稿后出图只走这一套。不要另起浅色清新风，也不要按题材换主色（薄荷绿 / 暖黄 / 沉稳蓝灰已废）。

实现：HTML/CSS → Playwright，画布按下面像素渲染。表内字号按 **CSS px** 用（原文 pt/px 并列）；`deviceScaleFactor: 1`，不要再乘 2。

思源黑体用 `Noto Sans CJK SC`（同族）。主字重 Bold + Regular；金句可用 Medium，注解可用 Regular/Light。标题不要上 Light。

## 色板（锁死）

| 角色 | 色值 | 用在哪 |
|---|---|---|
| 主底色 | `#0D0D0D` | 整页画布。暖黑，不要纯 `#000` |
| 卡片 | `#1A1A1A` | 次级容器、对比卡、金句框、时间线节点 |
| 强调红 | `#FF3B30` 或 `#E53935` | **唯一主强调**。只点核心金句、关键时间/数字、警示。禁止大面积铺红 |
| 对比青 | `#00E5FF` 或 `#00B0FF` | 「可控性 / 听话 / 正常 / 以前」等对照项，和红对打 |
| 主文字 | `#FFFFFF` | 标题、重点句 |
| 次文字 | `#E0E0E0` / `#B0B0B0` | 正文、说明 |
| 弱提示 | `#757575` | 页码、人名头衔、胶囊标签底 |

红 = 越界 / 退步 / 取消 / 金句 / 关键量。青 = 听话 / 可控 / 正常状态。两边都用红，对比就废了。

## 画布与边距

- 尺寸：`1242 × 1660`（3:4）
- 左右：60–80px
- 上下：80–100px（顶避开信息流控件，底留给页码）
- 标题锚点：每页标题顶边落在距画布顶 **160–220px**，左对齐。滑动时视线不跳。封面大字占上半屏，仍从这条锚点起笔
- 图文比：字 : 视觉（卡片/示意图）≈ **4:6 或 5:5**。不要整页纯字墙
- 行高：字号 × 1.4–1.5
- 段间距：字号 × 0.8–1.0

## 字号

| 层级 | px | 字重 | 用在哪 |
|---|---|---|---|
| 封面大标题 | 48–56 | Bold | 图1，信息流里要能认 |
| 内页主标题 | 36–40 | Bold | 图2 起，一字排开 |
| 金句大字 | 40–44 | Bold / Medium | 不超过封面字号 |
| 正文 / 对比卡 | 24–28 | Regular | 每行约 12–16 个汉字 |
| 引语 / 头衔 | 20–22 | Regular | 如图3 署名 |
| 小字注解 | 18–20 | Regular / Light | 如图6「你拉这边，那边就松」 |
| 标签 / 页码 | 16–18 | Regular | 胶囊标签、角标 `n/9` |

页码默认 `n/9`，放右上或右下，颜色 `#757575`。定稿写了 8 页就用 `n/8`，不要为凑 9 页而加空页。

## 固定版式（个人风格）

- 底部作者签名：用户账号名；未提供则留空
- 📌收藏卡、A/B/C 互动卡、胶囊标签：各篇同一套，不要每篇换皮
- 「你以为 / 其实」只出现在纠正假因果的页
- 常用组件：圆角卡片、双栏对比、时间线节点、金句左边框、箭头流程

每篇可变的只有装饰物（水印、示意图、时间线疏密），不是色板，也不是字号。

## 导出

- PNG 或 JPEG
- 单张 2–5MB。Playwright 默认 PNG 通常远小于此；不要为凑体积加噪声
- 出图后改字：只重渲改过的页，再对文案、导出文字、渲染脚本跑敏感词 grep

## 出图时不要做

| 旧习惯 / 借口 | 现在 |
|---|---|
| 浅色清新底、封面也浅色 | 一律 `#0D0D0D` |
| 按题材换薄荷绿 / 暖黄 / 蓝灰 | 色板锁死 |
| 正文 ≥44px（旧 skill） | 正文 24–28px，标题走表 |
| 红色铺满底或整卡 | 红只做点缀 |
| 对比页两边都用红 | 正常侧用青 |
| 标题每页高低不齐 | 锁 160–220px |
| 整页只有字 | 补卡片或示意图，压到 4:6 / 5:5 |
