# 小红书科技向调性

**完整准确优先。** 调性跟正文结构走，不按表抢认知差。
选调性前先用一句话写出素材真正的结构；那句话是什么，主调性就是什么。

小红书吃标题冲突、一页一点、可收藏清单——这些当钩子和辅页用。它们不是账号身份，也不要求每篇主结构都是认知差。同质化「你以为 / 其实」会伤辨识度。

## 三层不要混

| 层 | 每篇数量 | 作用 | 不是什么 |
|---|---|---|---|
| 口吻 | 始终叠一层，缓慢进化 | 读者凭这个认出是你 | 不是角度；不对标 Max；不要一帖换一套 |
| 主调性 | 只选 1 个，跟正文 | 决定封面和骨架 | 不是标题钩子，也不是必须的认知差 |
| 辅调性 | 0–2 个 | 收藏卡、一页信息卡、评论区问句 | 不能独立成篇（除非表里写了「可升主」） |

标题钩子（数字冲击 / 反常识 / 信息差）可以套在任何主调性上，但**钩子 ≠ 调性**。
反常识标题配收藏框架正文，可以；标题写「和你想的不一样」、分页却在堆新闻，不行。

## 口吻（辨识度：锁指纹，慢进化）

只跟仓库里已经定稿的小红书文案学说话，**不对标 Max，也不学群聊科技博主**。
样本：`posts/2026-10-01-anthropic-brakes/xiaohongshu.md`、`posts/2026-10-01-mcp-debate/xiaohongshu.txt`、`posts/2026-10-01-livenerf-opus-nerf/xiaohongshu.txt`。

**锁住（读者靠这些认出你）：**

- 正文以「我的判断：」起头，判断是结构洞察，不是情绪站队。
- 来源一句说清（专访 / 仓库 / HN），需要时「先说人话」把新词译成物件。
- 「翻完原文和评论，我觉得有 3 个点值得知道」——编号要点，每条能指回出处。
- 留余地：两边都有道理就写两边；还没有结论就写还没有。
- 金句冷静（「不是不敢跑，而是先装好刹车再跑」），比喻一次到位（刹车、手脚、说明书、奶酪）。
- 文末「以上根据公开××整理」+ A/B/C。选项互斥，且都能被正文支持。

**可以变：** 主调性随正文变；哪几页用「你以为 / 其实」随假因果变；比喻物件随题材变。
**怎么变口吻：** 只随新成篇微调，一次动一处（比如某次判断句更短、某次少用一个比喻）。不要为了「更像小红书」整套换皮。

| 写 | 不写 |
|---|---|
| 我的判断：…不一定是跑得最猛的那家 | 主包看到消息，第一反应是「这事终于来了」 |
| 先说人话：MCP 是给 AI 装的手脚 | 卧槽 / WTF / 家人们 / 内幕 |
| 不是打脸，是找到了更好的接法 | 圈子里都知道、未公开内幕 |
| 它现在还给不出答案 | 结论已定、必须选边 |
| 以上根据公开专访和公司公开文件整理 | 据悉、未公开备忘录 |

少用「据悉 / 值得注意的是」。观点必须被正文里的公开事实撑住；撑不住就写成「还看不清」。

## 主调性：按正文结构匹配

先写那句结构，再来查表。**没有优先级，不要命中就停。** 一件事往往同时有假因果、新名词和两难——主调性选读者看完最该带走的那个中心，其余降为辅或单页。不要为了更全面并成两个主。

| 正文结构是 | 主调性 | 页骨架（封面后） |
|---|---|---|
| 观众以为的因果是错的 | 认知差 / 反常识 | 纠正假因果的页用你以为/其实；不必九页全套 |
| 不懂这个抽象词，整件事就听不懂 | 概念降维 | 抽象定义 → 角色/物件映射 → 映射后的行为 → 映射的边界 |
| 不是谁对谁错，是两个合理目标互撕 | 结构性两难 | 目标 A → 目标 B → 为何不能同时拉满 → 类比 |
| 必须先看懂链路，角度才成立 | 机制拆解 | 触发 → 每步一页 → 哪一步开始变味 |
| 两条路（两家公司 / 两种训法 / 两种接法）在比的不是速度 | 对照 | A 做法 → B 做法 → 真正的分歧轴 → 判断标准 |
| 读者能带走一套下次还能用的检查项 | 收藏框架 | 每页一条可核对项 → 反例 → 怎么用 |
| 有一个「你下周就会做的同类事」 | 普通人翻译 | 新闻一句 → 映射到用户场景 → 可改的一刀 |
| 有真实步骤/设置，读者马上用得上 | 避坑实操 | 坑 → 为什么会踩 → 正确做法 → 清单 |

**默认辅、慎做主：** 信息差/冰山、时间线、数字冲击、情绪共鸣、争议站队。

本 skill **不做**：种草合集、盘点安利、副业变现、无事实的情绪稿。那些是另一类账号。

## 已落盘三篇：分页装置 ≠ 主结构

| 篇 | caption 真正的中心 | 分页上的「你以为/其实」 |
|---|---|---|
| Anthropic 刹车 | 对照：有条件放慢 vs 一刀切停 + 3 个可核对信号 | 用了，服务对照，不是身份 |
| MCP 改口 | 概念降维（手脚/手册）+ 两种接法各有道理 | 只用在「说过的话不会改」那一页量级 |

## 叠用

- 主调性 = 那句正文结构。热点、高信息差、反转标题，都不是认知差通行证。
- 假因果只占其中几页时：主可以是两难/对照/拆解，那几页再用「你以为 / 其实」。
- 新名词几乎必叠概念降维当解释工具，但不一定当主。
- 能写成 3–5 条可核对项时，📌收藏框架几乎必做辅页（已落盘都有）。
- 信息差若升主：正文必须有一句个人判断把散点钉成规律。没有判断 = 新闻汇总 = 弃用。
- 当天热点：口吻仍用指纹，结构仍写满分页。不要改成群聊速评。

文案第一行写死：`主调性：… / 辅：…`。封面服从主结构。
图片上不印调性名称（包括「认知差」）。

## 主调性卡片

### 1. 认知差 / 反常识

- **机制：** 纠正一条观众自己想不到的因果。钩子是「原来是这样」，不是「你看过这条新闻」。
- **何时：** 大众叙事有现成误解（叛变了、学坏了、已死、降智了）。「还不知道」不算；必须是「以为的因果是错的」。
- **不用：** 找不到假因果，只有新信息或新名词。这时改用概念降维或机制拆解。
- **标题：** 「X？其实是 Y」「真因和你想的不一样」。≤20 字，前 10 字就要露出冲突。
- **失败：** 分页在复述新闻；「其实」只是补充细节，没有翻转因果；为了反转标题把完整机制削掉。找不到假因果时不要硬当主。

### 2. 概念降维

- **机制：** 把专业概念映射成大众已经有的角色或物件。可迁移的是翻译能力，不是工具参数。
- **何时：** Agent、对齐、上下文、RSP、Codemode 这类词必须先变成「员工 / 说明书 / 刹车 / 手脚」。
- **不用：** 映射会歪（互补写成两派、比喻比原词更难懂）。映射必须写清**哪里不像**，否则就是假懂。
- **标题：** 「所谓 Agent，就是一个会自己找活的员工」「MCP 不是插件，是给 AI 装的手脚」。
- **失败：** 解释完定义就停，没有让读者用这个角色重新看事件；或生造「插座派」这类标签。

### 3. 结构性两难

- **机制：** 两头都是合理目标，拉满一边，另一边必崩。不是 bug，是目标函数的副产品。
- **何时：** 主动性 vs 可控性、速度 vs 刹车、上下文一次给满 vs 用到再给。
- **不用：** 其实有对错（造假、违规）。有对错就用认知差或避坑，不要两边各打五十大板。
- **标题：** 「不是训坏了，是两头没法一起要」「越主动，越难管」。
- **失败：** 写成「公司无良」或「AI 叛变」；没有类比，读者带不走张力。

### 4. 机制拆解

- **机制：** 把「它是怎么发生的」画成一条能指着看的链。
- **何时：** DNS 逃逸、工具调用占上下文、模型被切走，不拆开就只剩形容词。
- **不用：** 链路讲不清，或拆开会触发降敏（具体攻防步骤、利用方法）。能讲到「绕过障碍」这一层就停，不写可复现的操作。
- **标题：** 「一次『失控』其实走了这 4 步」。
- **失败：** 变成论文；或步骤里出现可跟做的攻击细节。

### 5. 对照

- **机制：** 两家/两法不在比谁快，在比选了哪根轴。
- **何时：** Anthropic 刹车 vs 别家猛跑；MCP vs 命令行；暂停训练 vs 公开风险报告。
- **不用：** 硬把互补写成对立（MCP vs Skill）。
- **标题：** 「两家 AI 公司，不是在比速度」。
- **失败：** 变成站队骂战；对照项不可核对。

### 6. 收藏框架

- **机制：** 读者收藏的是「下次还能用」的检查项，不是情绪。
- **何时：** 能写成 3–5 条可核对信号/步骤/原则。现有成品里的📌卡经常是它，也可以升主。
- **不用：** 条目不可执行（「要理性」「要关注安全」）。
- **标题：** 「判断 AI 公司真在乎安全的 3 个信号」「觉得模型变笨，先查这 4 件事」。
- **失败：** 清单每条都在重复同一句；没有反例。

### 7. 普通人翻译

- **机制：** 前沿事件 → 读者正在做的同类事。启发必须具体到「下次提示词少写一句 / 多写一句」。
- **何时：** 新闻本身离日常远，但机制同构（你让 Agent「自己想办法」＝同一训法的缩小版）。
- **不用：** 硬贴「对学生也有启发」却给不出动作。给不出就不要这一层。
- **标题：** 「你给 AI 的那句『自己想办法』，就是同一颗雷」。
- **失败：** 鸡汤；或把公司决策道德化成个人修养。

### 8. 避坑实操

- **机制：** 真实踩坑 + 可复制的正确做法。搜索流量和收藏都吃这一种。
- **何时：** 素材是工具、工作流、配置、评测，不是公司战略新闻。
- **不用：** 没有亲测或公开实测数据。禁止虚构「我试了三天」。
- **标题：** 「接 3 个 MCP，上下文先没了 72%」。
- **失败：** 安利腔；步骤无法照做。

## 辅调性（默认不独立成篇）

| 辅 | 用法 | 升主条件 | 失败 |
|---|---|---|---|
| 信息差 / 冰山 | 1 页卡：你看到 A，漏了 B/C/D，最后钉成一句规律 | 有判断能把散点收束；1000 字内压得住 | 新闻汇总、时间线堆砌 |
| 时间线 | 一页：日期 + 事件 + 变化点 | 几乎不升主 | 写成编年史 |
| 数字冲击 | 标题或单页放大一个量级差（331 次调用 → 一句结论） | 几乎不升主 | 数字不能指回出处；为了冲击而估 |
| 情绪共鸣 / 挫败感 | 开场 1 句或评论区问句。科技内容积极情绪低于大盘，「挫败」有消费意愿，但最容易撞同质 | 几乎不升主 | 无事实的焦虑稿，收藏弱 |
| 争议站队 | 文末 A/B/C，选项必须互斥且都能被正文支持 | 不升主 | 选项假对立刻被看穿 |

情绪共鸣若出现在正文，必须立刻接回事实或药方，不能停在「我好焦虑」。

## 同一则素材：怎么拆成不同调性

素材：某实验室暂停训练，因为模型学会了「绕过障碍」，而绕过障碍和越界在模型内部已经分不清。大众叙事是「AI 学坏了 / 叛变了」。

先写结构句，再选主。这篇同时有假因果、员工类比、两难——主选读者最该带走的中心，不是默认认知差。

| 调性 | 这一篇的核心句 | 建议 |
|---|---|---|
| 认知差 | 不是学坏了，是把「别偷懒」训得太成功 | 假因果是中心时做主；否则只做几页 |
| 概念降维 | 你让员工遇到困难别停，他就学会绕开规则 | 解释工具，几乎必叠，不一定当主 |
| 结构性两难 | 主动性和可控性是同一根绳子的两端 | 若读者该带走的是张力，可以升主 |
| 机制拆解 | 从「奖励主动性」到「越界」走了哪几步 | 能讲清就做 1–2 页，攻防细节不写 |
| 信息差 | 三个月第二次暂停，底下是一串异常，不是孤例 | **只做 1 页卡** |
| 收藏框架 | 下次看到「AI 失控」，先问这 3 句 | 做📌页 |
| 普通人翻译 | 你写的「自己想办法、别轻易停」是同一训法 | 有动作再做 |
| 金句页 | 不是不敢跑，是先装好刹车再跑 | 对标已落盘图 9，冷静收束，不演情绪 |
| 情绪共鸣 | AI 越强越焦虑 | **只放评论区** |

选完后不要把上表全写进一篇。主 1 + 辅 ≤2。

## 常见跑偏

| 借口 | 处理 |
|---|---|
| 「科技评论就是认知差 / 命中就停」 | 先写正文那句结构。假因果只是其中一种中心。 |
| 「完整就不够小红书」 | 小红书吃可收藏的完整，不是削薄的反转。准确优先。 |
| 「每篇都你以为/其实才有辨识度」 | 辨识度在口吻指纹，不在认知差版式。有假因果的页再用。 |
| 「风格要一次定死或整套换皮」 | 指纹锁住，主调性随正文变，口吻随新成篇一次改一处。 |
| 「信息多才专业」 | 1000 字内，信息差只能当冰山一角卡，判断必须有。 |
| 「要对标 Max / 写成群聊速评」 | 口吻只跟 `posts/` 已落盘文案。判断冷静，不用主包/卧槽/内幕腔。 |
| 「要有料才像懂行」 | 料 = 公开材料里被忽略的结构，不是编的内幕。 |
| 「情绪向也有 TGI」 | 可以当钩子，不能当主粮。 |
| 「多写几种调性更全」 | 一篇一个主。多出来的放到下一篇或评论区。 |
